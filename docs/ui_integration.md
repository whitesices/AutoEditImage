# Desktop UI Integration

The current project now combines two workflows:

- Existing CLI/model pipeline: text or point prompts use Grounding DINO and SAM2.
- Desktop layer workflow: open an image, draw a rectangle, preview a mask, create
  layers, and export cropped transparent PNG assets with metadata.

## Run

```powershell
.venv\Scripts\python.exe main.py ui
.venv\Scripts\python.exe main.py ui -i GAS2.png
```

## UI Workflow

1. Click `Open Image`.
2. Drag on the canvas to create a rectangle selection.
3. Review the cyan mask preview generated by the local OpenCV/rectangle
   segmenter.
4. Click `Create Layer`.
5. Rename, hide/show, delete, or export layers in the right panel.
6. Click `Export All` to write:

```text
Export/
+-- layers/
+-- masks/
+-- project.json
+-- preview.png
```

## AI Text Extraction In UI

After opening an image, enter a command in the toolbar, for example
`cut out a red car and save to ./my_outputs`, then click `Run NL Cut`.

The command parser extracts the target prompt and optional export directory.
This calls the existing `ExtractionPipeline`, which loads Grounding DINO and
SAM2, converts the returned masks into UI layers, optionally exports the project,
then unloads the models. This path is intentionally model-backed and may
download weights on first use.

Supported command examples:

```text
cut out a man with sword
cut out a man with sword and save to ./my_outputs
抠出 a man with sword 导出到 ./my_outputs
抠出右边的人 导出到 ./my_outputs
```

## OpenAI-Compatible LLM Parser

Click `LLM Settings` in the toolbar to enable an external command parser.
The parser supports OpenAI-compatible chat/completions APIs, including DeepSeek.

Example:

```text
API URL: https://api.deepseek.com/v1
Model: deepseek-chat
API Key: <your key>
```

The app normalizes the URL to:

```text
https://api.deepseek.com/v1/chat/completions
```

The LLM returns JSON with:

```json
{
  "target_prompt": "a man",
  "location_hint": "right",
  "auto_export": true,
  "output_dir": "./my_outputs",
  "max_results": 1
}
```

`target_prompt` is passed to Grounding DINO. `location_hint` is used to sort and
limit detections before SAM2 segmentation. If the API fails, the app falls back
to deterministic local parsing.

## Architecture

- `app/`: PySide6 widgets and main-window orchestration.
- `core/`: layer data contracts, mask utilities, project state, exporter.
- `segmenters/`: UI segmentation backends. `OpenCVSegmenter` is the default
  local backend and falls back to a filled rectangle when needed.
- `src/`: original CLI/model pipeline.

The UI keeps full-canvas `uint8` masks internally and crops only at export time.
`project.json` preserves source-canvas coordinates so downstream tools can place
layers back onto the original image.
